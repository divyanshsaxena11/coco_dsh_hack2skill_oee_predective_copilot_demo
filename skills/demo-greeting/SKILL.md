# Demo Greeting Skill

When the user invokes this skill, follow these steps:

1. Greet the audience with an enthusiastic welcome to the CoCo Desktop demo
2. List the 3 hooks that are currently configured:
   - UserPromptSubmit: Context injection (team reminders)
   - PostToolUse: Auto-header for SQL files
3. Mention that this skill itself is a live example of how custom skills work
4. Ask the audience what they'd like to see demonstrated next

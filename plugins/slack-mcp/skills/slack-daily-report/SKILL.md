# Slack Daily Report

When invoked, generate and send a daily plant health summary to #mfg-copilot-alerts.

## Step 1: Gather current data

Run these queries using snowflake_sql_execute:

```sql
-- Current OEE
SELECT ROUND(AVG(OEE)*100,1) AS AVG_OEE,
       ROUND(AVG(AVAILABILITY)*100,1) AS AVG_AVAIL,
       ROUND(AVG(PERFORMANCE)*100,1) AS AVG_PERF,
       ROUND(AVG(QUALITY)*100,1) AS AVG_QUAL
FROM MFG_COPILOT_DB.CORE.OEE_INTERVAL
WHERE INTERVAL_START >= MFG_COPILOT_DB.GOVERNANCE.CURRENT_AS_OF() - INTERVAL '8 HOURS';
```

```sql
-- Open downtime events
SELECT ASSET_ID, STOP_CATEGORY, ASSOC_METHOD, DURATION_MIN
FROM MFG_COPILOT_DB.CORE.DOWNTIME_EVENT
WHERE STOP_START >= MFG_COPILOT_DB.GOVERNANCE.CURRENT_AS_OF() - INTERVAL '24 HOURS'
ORDER BY DURATION_MIN DESC
LIMIT 5;
```

```sql
-- Assets at risk
SELECT ASSET_ID, RISK_TIER, HEADLINE
FROM MFG_COPILOT_DB.CORE.ASSET_HEALTH_SNAPSHOT
WHERE RISK_TIER IN ('HIGH','CRITICAL')
ORDER BY RISK_TIER DESC;
```

## Step 2: Format the message

Compose a Slack message using this template:

```
:factory: *Daily Plant Health Report*
:clock3: As of: {CURRENT_AS_OF timestamp}

*OEE Summary (last 8 hours)*
• Overall: {AVG_OEE}%
• Availability: {AVG_AVAIL}% | Performance: {AVG_PERF}% | Quality: {AVG_QUAL}%

*Top Downtime Events (24h)*
{For each event: • {ASSET_ID}: {STOP_CATEGORY} — {DURATION_MIN} min ({ASSOC_METHOD})}

*Assets at Risk*
{For each: • {ASSET_ID}: {RISK_TIER} — {HEADLINE}}

_Report generated by MFG Copilot via CoCo_
```

## Step 3: Send to Slack

Use the `send_message` MCP tool to post to channel **#mfg-copilot-alerts**.

If the channel is not found, list channels first using `list_channels` to find the correct channel ID, then send.
